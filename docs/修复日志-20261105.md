### 3.1 迁移记录比文件多 1 行（孤儿记录，非缺陷）
DB `schema_migrations` 含 `0008_real_market` 与 `0008_replay` 两条**不同版本串**。仓库仅有 `0008_replay.sql`（`0013_real_market.sql` 是另一文件）。
- 根因：`0008` 的迁移文件历史上曾被命名为 `0008_real_market.sql`，后重命名为 `0008_replay.sql`；首次运行时 `0008_real_market` 已落表，重命名后 `0008_replay` 又补录，故两行并存。
- 影响：`migrate.js` 以 `version TEXT PRIMARY KEY` 去重，已应用的版本直接跳过，孤儿记录**不会触发重放**，对运行无任何影响。
- 处置：**不修复**（属历史残留；删除该行是 DB 变更但无功能收益，且违反「无必要不改生产数据」原则）。

### 3.2 `stageZeroService.js` 仓库 ≠ 镜像（已知漂移，需计划性重建对齐）
- `src/services/stageZeroService.js`：仓库 `md5=3410bc91`，镜像/容器 `md5=199581fa` → **DIFF**。
