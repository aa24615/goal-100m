## 二、优先级模型说明（P0 ~ P5）

需求文档只定义了 P0 / P1 / P2 三级**业务优先级**。测试需要覆盖正常流程、边界与异常，
因此本矩阵在业务优先级之上补充了三个**测试维度优先级**，二者正交：

| 级别 | 含义 | 判定标准 |
|---|---|---|
| **P0** | 核心主流程 / 差异化根基 | 失败即阻断发布；对应 REL-*、RQ-62、RQ-79 |
| **P1** | 差异化功能 | 竞品未覆盖的能力；对应 RQ-80/82/83/84/85/90 |
| **P2** | 留存与体验补齐 | 不影响可用性的增强；对应 RQ-86/81/89 |
| **P3** | 边界与异常 | 脏入参、空数据、非法值、越权、NaN/Infinity、业务拒绝码 |
| **P4** | 性能与并发 | 大样本、高频调用、耗时预算 |
| **P5** | 兼容性与回归 | 旧字段语义不倒退、口径同源、常量一致、流程留痕 |
