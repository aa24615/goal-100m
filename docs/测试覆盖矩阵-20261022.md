## 5. 测试隔离约定

- 集成测试跑在独立的 `papertrade_test` 库，与开发库 `papertrade` 互不干扰。
- 每个测试文件的 `before()` 会调用 `resetDb()` **先 DROP SCHEMA 再重建**，随后执行全量迁移。
  原因：用例会不断注册新账号，不清理的话用户数随执行次数线性增长（曾累积到 94 个），
  直接踩中排行榜 `TOP_N = 50` 截断，导致断言随机失败。
- 迁移必须**可重复执行**（`IF NOT EXISTS` / `ADD COLUMN IF NOT EXISTS`），否则重建后跑不通。
- 排行榜缓存按 period 缓存**全量排名**，切片与「钉住自己」放在路由层按 `req.userId` 做，
  这样缓存不会因不同用户而互相污染。

## 6. 运行方式

```bash
# 后端单测
cd backend && npm test

# 后端集成（会连 papertrade_test，需先起 postgres:5433）
cd backend && npm run test:integration

# 前后端全量
cd backend && npm run test:all

# 前端测试 + 类型检查 + 构建
cd frontend && npm test
cd frontend && npx tsc --noEmit
cd frontend && npm run build
```
