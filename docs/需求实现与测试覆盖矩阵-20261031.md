## 4. 本期修掉的真实缺陷（测试发现的，不是需求写的）

1. **`dedupeKeyOf` 对数字时间戳静默失效**：`Date.parse(1793385300000)` 返回 `NaN`
   → 所有数字时间戳都会回落到「当前时刻」→ **所有事件落进同一个时间窗，去重把真实动作全吃了**。
   由「跨窗口的多次真实打开仍分别计数」这条用例暴露。
2. **达标线作用在了错误的量上**：期望值的达标线是 `t > 1.96`，但 `pass` 拿的是期望值本身（通常 ±1R）
   → 永远判「未过线」，达标线形同摆设。改用显式 `thresholdOn: 't'`。
3. **`evaluateEffectiveCompletion` 里的 TDZ**：`const score = src.score && typeof score === 'object' ? ...`
   在初始化器里引用同名 const 会命中 TDZ，`typeof` 对 TDZ 变量抛 ReferenceError
   （与「未声明变量返回 undefined」不同）。
4. **`routes/analytics.js` 漏 import `pool`**：新增的 5 个路由全部 500。集成测试直接抓到。
5. **撮合拒绝原因不留痕**：参数校验阶段（方向错误 / 非整手）在 `simulateReplay` 之前就 throw，
   RQ-150 的「被拒绝的委托去哪了」对这些最常见的拒绝**完全没覆盖**。已改为全阶段落库。
6. **F-78 零引用缺陷**：`settlementAuditService`（422 行）与 `dualBaselineService`（213 行）
   全仓库引用数为 0 且未提交。本期两处均已接线（`/blind/:id/settlement/audit`、`/blind/:id/baseline`）。
