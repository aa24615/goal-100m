## 0. 测试级别约定（沿 v7 起六档，P3/P4/P5 是**测试级别**而非产品优先级）

| 测试级别 | 含义 | 说明 |
|---|---|---|
| **P0** | 主流程 | 需求核心路径、正常流程 |
| **P1** | 差异化 | 与竞品 / 旧口径的差异点、样本不足护栏 |
| **P2** | 留存体验 | 用户投入前 / 后的体验护栏（v17 无 P2 需求，相关项并入 P1） |
| **P3** | 边界异常 | 空值 / 越界 / 缺失 / 畸形输入 |
| **P4** | 性能并发 | 大样本 / 批量 / 高吞吐 |
| **P5** | 兼容回归 | 历史遗留口径 / 旧字段 / 防再次漂移 |

> 产品侧优先级（需求表）只定义 P0 / P1；P3/P4/P5 是测试作者对「覆盖度」的分级，二者不要混用。
