## 5. 本期踩坑（测试层，非 src）

1. `effectiveCompletionService.evaluateEffectiveCompletion` 的「完成」口径来自 `completionContract.isCompleted`：
   **仅 `status==='FINISHED'` 不够**，还须 `finished_at` 存在且 `session.score` 为对象（"结算并出成绩卡"）。
   初版用例只给 `status` 导致被误判 `not_finished`——已修正 fixture（补 `finished_at` + `session.score`）。
2. `evaluateEffectiveCompletion` 读 `durationSec` 优先取 `score.durationSec`，故「太短」用例须把 `durationSec:5` 放进 `session.score` 而非顶层。
3. RQ-216 与 RQ-218 是 v23 新增覆盖目标：此前 v21/v22 把 RQ-216 槽位填的是「外部真人」、RQ-218 槽位填的是「冻结」，
   本次按 v23 权威映射把这两个槽位改为 `effectiveCompletionService` 与 `activityRegressionService`，避免"覆盖假象"。
