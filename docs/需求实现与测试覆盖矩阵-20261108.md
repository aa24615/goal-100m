## 8. 发布与部署说明

本版仅新增**测试文件 + 文档**，未改动任何 `src/` 源码，因此**无需重建镜像 / 重启容器**（重建得到的是与 v18 完全一致的镜像，纯属浪费）。若后续在 RQ-195 完成前插入任何 src 改动，须走标准发布链路：

1. `git commit` → `git push origin main`（双推 GitHub `aa24615/goal-100m` + CNB `zyan2026/mm8888`）；
2. 本机 `npm run build`（前端镜像只 COPY 本机 `dist`）；
3. `docker-compose up -d --build backend` → **必须 `docker restart mm8888-frontend-1`**（nginx 缓存上游 IP）；
4. `DATABASE_URL=... node src/scripts/verifyRelease.js` 发布后六项断言。

> 本机生产入口为 `http://localhost:8866`（原 8080 被 url2pic 占用）；`docker compose`（插件版）不可用，必须用 `docker-compose`。
