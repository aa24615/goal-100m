### 0.1 关于「产品名称待补充」

### 0.2 v3 → v4：本版与上版的关键差异（最重要的一条）

v3 的核心判断是「数据地基已建、用户价值未兑现」，并给出了 RQ-01～35 共 35 项需求。**本次实地复核确认：这 35 项已基本交付**，同时产品发生了一次**根本性变更**——行情从自研随机游走切换为**真实 A 股数据**。

| 变化 | 复核结论（实地） |
|---|---|
| 行情数据源 | 新增 `datasource/eastmoney.js`（主）+ `sina.js`（兜底，带熔断与冷却恢复）；同步脚本 `npm run sync:market` |
| 标的池 | **28 只虚拟标的 → 5576 只真实 A 股标的**；stocks 表新增 `exchange / listing_date / market_cap / sector` |
| 历史行情 | **537 万根真实日线，覆盖 1147 个交易日**；新增 `trade_calendar`（trade_date → 稠密 seq，专为回放步进设计） |
| 实时行情 | 移除随机游走，`services/quoteFeed.js` 按节奏拉全市场快照并应用真实价 |
| v3 需求交付 | 回放 / 复盘 / 引导 / 剧本（8 关）/ 房间赛 / 超额收益 / 能力雷达 / 委托管理 / 交易日状态 / 重置审计 / 偏好 / 埋点后端 **均已落地**（详见 6.1 交付验收表） |

**因此 v4 的核心判断再次变化**：

> **功能骨架已经齐了，但产品的「身份」还没换过来。**
> 产品在两周内从「28 只虚拟标的的练习盘」变成了「5576 只真实 A 股标的 + 537 万根真实历史日线的训练场」，但**对外口径、规则精度、标的治理、运营重心、文档说明仍停在旧版本**——用户看到的免责声明还写着「行情均为虚拟仿真」，涨跌停仍一刀切 ±10%，5576 只标的只有一个搜索框和 15 条分页。
>
> 与此同时，真实历史数据打开了一个**国内近乎空白、海外已被验证为付费品类的卡位**：A 股真实历史行情回放训练（Bar Replay）。这是本产品目前唯一可持续的差异化来源。

本版所有诊断、创新与需求，围绕两条主线展开：**① 把产品口径与规则校正到「真实行情」的新身份；② 把 537 万根真实日线变成别人拿不走的训练资产。**

### 1.3 竞品空白与行业趋势（创新机会的来源）

1. **「回放训练」在海外已是一个被付费验证的独立品类**。公开资料显示，以 TradingSim、FX Replay 为代表的回放训练工具按订阅收费（FX Replay 约 $35/月起），核心卖点是「会话级回放 + 多标的同步 + 逐笔数据 + 决策书签 + 绩效分析」；TradingView 亦把 Bar Replay 与 Paper Trading、The Leap 竞赛并列为三条标准学习路径。**而在 A 股场景，主流模拟盘仍停留在「实时跟着真盘练」，缺少可反复重开的历史回放训练产品。**
2. **回放训练的关键不是「能回放」，而是「能挑出值得练的那一段」**。成熟工具的差异点已从播放器转向**行情筛选器**（按波动率、涨跌幅、板块、形态定位历史片段）与**决策标记**（在关键 bar 上打书签并回看）。这决定了用户是「随便拖一段」还是「有目标地刷」。
3. **真实行情 ≠ 训练可信**。海外评测反复强调模拟器的「执行真实性」：订单类型、成交约束、PDT 等规则是否贴近真实，直接决定训练能否迁移。这提示**规则精度本身就是产品价值**，而非技术细节。
4. **AI 的可靠价值在「复盘」而非「预测」**。行业共识仍是：用 AI 做交易日志分析、行为模式识别与即时反馈，可信度高、合规风险低；用于选股与收益承诺则风险极高。
5. **绝对收益榜单无法区分运气与能力**。本产品已计算超额收益，但尚未把它变成默认评价视角；这是低成本、高杠杆的信任杠杆。

## 2. 缺陷诊断

> 聚焦用户体验、业务流程与用户价值，不含技术实现细节。严重程度按「影响用户面 × 对核心闭环的阻断程度 × 风险不可逆性」评估。

### 2.1 高严重程度（9 项）

| 编号 | 问题现象 | 影响的用户与场景 | 严重程度 |
|---|---|---|---|
| F-01 | **对外口径与实际严重不符**：全局免责声明写「行情与资金均为虚拟仿真」、登录页写「所有资金与行情均为虚拟」、README 写「所有行情均为虚拟仿真」——但系统实际展示的是**真实 A 股实时行情与真实历史日线** | 全体用户与所有对外场景。既误导用户认知，又叠加**第三方行情数据再分发的授权合规风险**（Q1） | 高 |
| F-02 | **5576 只标的只有「搜索框 + 15 条/页」**：`sector`（真实行业）已同步入库、索引已建，**前端无板块/行业/市场/市值筛选，无涨跌幅以外的排序维度** | 所有想在全市场找标的的用户；新手面对 5576 只直接放弃（选择瘫痪） | 高 |

| F-06 | **密码找回在生产环境「假成功」**：SMTP 未配置时服务端仍返回「已发送重置邮件」，生产环境不回传令牌，用户永远收不到 | 所有忘记密码的用户；不仅失联，还被误导为「邮件在路上」，二次伤害 | 高 |

| F-09 | **README 与产品严重脱节**：仍写着「随机游走模拟 28 只标的」「默认 T+0」「所有行情均为虚拟仿真」，未提及真实数据接入、同步脚本与回放/复盘/剧本/房间赛等已上线功能 | 新人接入、协作方与外部读者；文档错误会持续放大为决策错误 | 高 |

|---|---|---|---|
| F-10 | **回放只有日期可选，没有「行情筛选器」**：537 万根日线只能用起止日期定位，无法按涨跌幅、波动率、板块、形态挑出「值得练的那一段」 | 想针对性训练的用户；回放沦为随机拖一段，训练目标缺失 | 中 |
| F-11 | **剧本训练场用种子合成行情，与真实历史是两套世界观**：8 关均为 `seed` 生成的虚构行情，与真实回放互不打通 | 认真训练的用户；「练虚构行情」的说服力远低于「练真实历史」，且两套成绩无法比较 | 中 |
| F-12 | **个股详情只有 OHLC + 成交量**：无板块归属、市值、换手、同业对比、上市日期等任何可解读信息 | 想理解「为什么涨跌」的用户；真实标的却没有基本面上下文 | 中 |
| F-13 | **回放、剧本、房间赛、复盘的成绩彼此孤立**，没有统一的成长档案与累计进度 | 所有持续训练的用户；努力不被累积，缺少长期目标 | 中 |
| F-14 | **无「今天练什么」的推荐**：没有任何每日训练入口或任务清单，用户需自行决定练什么 | 新手与低频用户；每次登录都要重新做决策，流失在决策点 | 中 |
| F-15 | **移动端仅基础适配**：抽屉导航与边距收窄已做，但宽表格（行情/交易记录）、图表与回放页在手机上仍难用 | 通勤/课间想练的用户 | 中 |
| F-16 | **超额收益已算出来，但不是默认视角**：排行榜仍以绝对收益为主排序，超额收益未成为主指标与默认排序 | 想证明能力的高手；普涨行情下榜单仍会失真 | 中 |
| F-17 | **新手没有「从哪只开始」的收敛路径**：标的从 28 只涨到 5576 只后，新手的起步路径反而更模糊 | 首次使用的新手；首日流失 | 中 |
| F-18 | **行情数据的时间与来源不透明**：页面未显示最后更新时间、数据来源与可能延迟 | 对数据时效敏感的用户；无法判断看到的是否为最新价 | 中 |
| F-19 | **房间赛与社交传播机制弱**：无邀请回流链路、无好友对比、无赛后战绩分享闭环 | 有社交诉求的用户；房间赛拉不动人则功能空转 | 中 |

### 2.3 低严重程度（5 项）

| 编号 | 问题现象 | 影响的用户与场景 | 严重程度 |
|---|---|---|---|
| F-20 | UI 术语与新身份冲突：状态栏提示仍写「虚拟行情的交易日序号」，README 提「压缩模式交易日」 | 细心用户；术语不一致削弱专业感 | 低 |
| F-21 | 导出与战绩分享卡功能已建，但入口不显眼、转化路径长 | 想展示成果的用户 | 低 |
| F-22 | 无键盘快捷键与布局自定义 | 高强度训练用户；操作效率受限 | 低 |
| F-23 | 持仓个股的停牌、异常波动、重大价格变动无任何提醒 | 持仓用户；错过关键变化 | 低 |
| F-24 | 无障碍（键盘可达、读屏、对比度）未做校验 | 有障碍用户 | 低 |

**统计**：共 24 项，其中高 9 项、中 10 项、低 5 项。
**核心结论**：高严重项可分为两类——**「口径与规则失真」（F-01/03/04/09，4 项）**和**「真实数据规模带来的治理缺口」（F-02/05/06/07/08，5 项）**。前者是身份问题，必须先行；后者是规模问题，决定留存。

## 3. 创新机会

> 五个方向均建立在「已握有 5576 只真实标的 + 537 万根真实历史日线 + 稠密交易日历」这一资产之上，并优先补齐竞品的结构性空白。

### I-1　A 股真实历史行情回放训练（第一差异化押注）

- **解决的痛点**：真实行情只能「过一遍」，想练手必须等开盘；而国内 A 股侧缺少可反复重开的历史回放训练产品（海外同类已按订阅制收费，需求被验证）。
- **做什么**：把真实日线变成训练场——提供**行情筛选器**（按板块/区间涨跌幅/波动率/最大回撤挑出值得练的历史片段）、**多标的同步回放**、**决策书签**（在关键 bar 打标记并回看）、倍速/单步/倒带，回放中下单并出成绩。
- **预期价值**：把「看盘」变成「练盘」，单位时间练习次数提升一个数量级；形成竞品靠实时行情无法复制的壁垒；是唯一可能支撑未来付费的能力。
- **行业佐证**：TradingView 将 Bar Replay 列为三条标准学习路径之一；TradingSim/FX Replay 已把会话级回放 + 决策书签 + 绩效分析做成付费品类。

### I-2　每日训练题与「从哪只开始」的收敛路径

- **解决的痛点**：5576 只标的带来的选择瘫痪；新手不知道今天该练什么、从哪只开始。
- **做什么**：每天基于真实行情自动生成「今日训练卡」——3～5 只有明确练点的标的（如「今日振幅最大」「连续缩量回调」）+ 1 段推荐回放行情 + 1 个针对性剧本关，形成一条最短练习路径。
- **预期价值**：把「登录后自己想办法」变成「登录后直接开练」，直接压降首日与回访流失；运营成本低，可全自动生成。

### I-3　休市即训练（把 75% 的静止时间变成使用时间）

- **解决的痛点**：真实行情下非交易时段产品完全静止（F-07），用户打开即失望。
- **做什么**：休市时首页自动切换为训练模式——「已收盘，来练一段」+ 当日行情自动生成的复盘摘要 + 推荐回放段 + 今日训练卡；开盘前给出预告。
- **预期价值**：把产品的有效使用时间从「每天 4 小时」扩展到「全天」，是所有留存指标中杠杆最大的一项。

### I-4　真实规则仿真（让「练的」和「真的」一致）

- **解决的痛点**：涨跌停一刀切、无停牌与退市建模（F-03/F-04），训练结果不可迁移。
- **做什么**：按板块与市场层级应用真实涨跌幅约束（ST ±5%、创业板/科创板 ±20%、北交所 ±30%）、停牌不可交易、新股上市首日规则、退市整理期提示，并在 UI 上明示当前标的适用的规则。
- **预期价值**：规则精度本身就是训练产品的核心价值；真实标的 + 真实规则 = 「练完能直接用」的可信承诺。

### I-5　成长档案与能力认证（替代「只看收益率」）

- **解决的痛点**：回放、剧本、房间赛、复盘的成绩彼此孤立（F-13），用户努力不被累积；绝对收益榜无法区分运气与能力（F-16）。
- **做什么**：把四类训练成绩汇入统一成长档案，形成等级/徽章与能力雷达（择时/选股/风控/纪律），并把超额收益设为排行榜默认视角。
- **预期价值**：给持续训练者长期目标，给高手可证明的荣誉；让榜单从「比谁胆子大」变成「比谁真的会」。

## 4. 新功能模块拆解

### M1　真实历史回放训练场（升级版时间机器）

| 项 | 内容 |
|---|---|
| **目标用户与场景** | 所有想提高练习密度的用户；典型场景：晚上花 20 分钟，用筛选器挑出「某板块 2024 年那段急跌」，带 3 只标的同步回放练一遍，在关键 bar 打标记，结束后回看自己的决策点 |
| **核心功能点** | ① **行情筛选器**：按板块/区间涨跌幅/波动率/最大回撤/形态定位可练的历史片段；② **多标的同步回放**（自选股或筛选结果，同一时间轴）；③ **决策书签**：在任意 bar 打标记并附一句理由，结束后可回看；④ 倍速/暂停/单步/倒带，回放中按真实规则下单并出成绩；⑤ 同一片段可重复训练，成绩保留并可对比 |
| **优先级** | **P0** |
| **关键指标** | 周活跃用户中使用回放训练的比例 ≥ 35%；人均每周回放训练次数 ≥ 3 次；单次训练平均时长 ≥ 8 分钟；使用筛选器开启回放的占比 ≥ 50% |
| **验收标准** | 同一片段重复回放两次，行情序列与成交结果完全一致（可复现）；筛选器条件与返回的行情片段参数一致（可逐条核对）；多标的回放时间轴严格对齐；书签可持久化并在成绩页回看；回放中的任何操作不写入真实账户与排行榜 |

### M2　标的治理与每日训练题

| 项 | 内容 |
|---|---|
| **目标用户与场景** | 面对 5576 只标的不知所措的新手与回访用户；典型场景：登录后直接看到「今日训练卡」，点进去就是一只标的 + 一段回放 + 一个关卡 |
| **核心功能点** | ① 行情中心筛选器：按行业板块、市场层级（沪/深/创/科/北）、市值区间、涨跌幅筛选并排序；② 个股详情补齐板块、市值、换手、上市日期与同业对比；③ **今日训练卡**：每日自动生成 3～5 只有练点的标的 + 1 段推荐回放 + 1 个推荐剧本关；④ 新手起步清单（如「先从市值 largest 的 10 只开始」）；⑤ 行情最后更新时间与数据来源在页面明示 |
| **优先级** | **P0** |
| **关键指标** | 行情中心筛选器使用率 ≥ 40%；今日训练卡点击率 ≥ 30%；新用户首日完成首笔交易比例 ≥ 60% |
| **验收标准** | 筛选条件与结果集完全匹配（可按条件反查校验）；板块/市值/换手数据与同步入库值一致；今日训练卡每日自动更新且内容与当日真实行情相关；个股详情页显著标注数据来源与更新时间 |

### M3　口径与规则真实化

| 项 | 内容 |
|---|---|
| **目标用户与场景** | 全体用户（口径）+ 用真实标的训练的用户（规则）；典型场景：买入一只 ST 股时，系统按 ±5% 约束并明确提示「该标的涨跌幅限制为 ±5%」 |
| **核心功能点** | ① **真实涨跌幅约束**：ST ±5%、创业板/科创板 ±20%、北交所 ±30%、主板 ±10%，下单与撮合均按所属板块生效；② **停牌/退市/新股状态**：无报价标的不可交易并提示状态，退市整理期显著标识；③ **免责与来源口径统一改写**：全局声明改为「真实行情 + 模拟资金与模拟交易」，标注数据来源与延迟说明；④ README 与对外文档同步更新；⑤ 状态栏与 UI 术语去除「虚拟行情」等过时表述 |
| **优先级** | **P0** |
| **关键指标** | 规则类下单拒绝提示准确率 100%；口径不一致的界面文案清零（上线前全量排查） |
| **验收标准** | 随机抽取各板块标的，涨跌幅约束与所属板块规则完全一致；停牌标的无法成交并给出明确提示；全局免责声明、登录页、README 三处口径一致且与实际一致；法务/合规对数据来源披露确认通过 |

### M4　休市训练与留存引擎

| 项 | 内容 |
|---|---|
| **目标用户与场景** | 下班后、周末、节假日打开产品的用户；典型场景：周六上午打开，首页是「已收盘 · 来练一段」，下方是昨日行情生成的复盘摘要与推荐训练 |
| **核心功能点** | ① 休市态首页自动切换为训练模式（复盘摘要 + 推荐回放 + 今日训练卡）；② 开盘前预告与倒计时；③ 每日练习打卡与连续天数（纯荣誉性质）；④ 新手任务清单与里程碑；⑤ 数据源异常时页面明示「行情更新暂缓，可先去训练」 |
| **优先级** | **P1** |
| **关键指标** | 非交易时段活跃会话占比 ≥ 30%；7 日留存率提升 ≥ 10 个百分点；连续打卡 ≥ 3 天的用户占比 ≥ 20% |
| **验收标准** | 休市态在收盘后自动切换且无需刷新即可感知；推荐内容与最近一个交易日的真实行情相关；打卡与里程碑均为荣誉性质，不涉及任何实物或现金奖励；数据源中断时页面有明确状态提示且不误导 |

### M5　成长档案与能力认证

| 项 | 内容 |
|---|---|
| **目标用户与场景** | 持续训练、有荣誉诉求的用户；典型场景：一个月后打开成长档案，看到回放/剧本/房间赛的累计成绩、能力雷达与等级变化 |
| **核心功能点** | ① 统一成长档案：回放、剧本、房间赛、复盘成绩汇聚；② 等级与徽章（纯荣誉）；③ 能力雷达（择时/选股/风控/纪律）与历史变化曲线；④ 排行榜**默认按超额收益**排序，绝对收益作为次要维度；⑤ 战绩导出与分享卡入口前置 |
| **优先级** | **P1** |
| **关键指标** | 活跃用户成长档案访问率 ≥ 40%；超额收益作为默认视角后榜单页停留时长提升 ≥ 20%；分享卡周生成量 ≥ 50 次 |
| **验收标准** | 四类成绩口径一致且与各自来源页数据一致（误差 ≤0.01 元）；超额收益 = 用户收益率 − 同期大盘收益率，口径在页面明示；分享卡不含任何未脱敏的个人身份信息 |

### M6　数据可观测与数据源治理（底座）

| 项 | 内容 |
|---|---|
| **目标用户与场景** | 产品与运营侧（度量）+ 全体用户（数据源状态可见）；典型场景：看板能看到「本周回放了多少次、复盘被查看了多少次」，用户能看到「行情最后更新于 xx:xx」 |
| **核心功能点** | ① **前端埋点接通**：在回放开始/完成、复盘查看、房间赛参与、引导完成、打卡等节点真实上报；② 关键指标看板（日/周维度，保留 ≥180 天）；③ 数据源状态可见：最后更新时间、来源、延迟与中断提示；④ 同步任务失败告警与用户侧降级提示 |
| **优先级** | **P0** |
| **关键指标** | 8 类关键事件上报成功率 ≥ 99%；看板可回溯 ≥180 天；数据源中断的用户侧提示覆盖率 100% |
| **验收标准** | 埋点事件在前端真实触发并可在后端统计到（按日/周可查）；口径文档与上报字段一致；行情页可见最后更新时间；数据源中断时页面有明确提示且不静默停更 |

### M7　移动端与长尾体验

| 项 | 内容 |
|---|---|
| **目标用户与场景** | 手机浏览器访问的用户；高强度训练用户；典型场景：通勤时用手机看今日训练卡并完成一次回放训练 |
| **核心功能点** | ① 行情列表、个股、交易面板、回放页的移动端适配（表格转卡片、图表自适应）；② 键盘快捷键与布局记忆；③ 持仓异动提醒（停牌、异常波动）；④ 无障碍校验（键盘可达、读屏标签、对比度） |
| **优先级** | **P2**（其中回放页移动适配随 M1 一期交付） |
| **关键指标** | 移动端会话占比 ≥ 25%；移动端页面跳出率下降 ≥ 15 个百分点 |
| **验收标准** | 主流手机宽度下无横向滚动、无遮挡、按钮可点击；快捷键不干扰输入；提醒频率可控且不骚扰；关键操作支持键盘可达与读屏朗读 |

## 6. 汇总结论：改造优先级与实施顺序

### 6.1 v3 需求交付验收

见 0.3 节：**29 项完整交付、6 项部分交付**（埋点未接通、移动端未完整、密码找回无 SMTP、剧本用合成行情、文案口径失真、超额收益非默认视角）。剩余缺口即 v4 的输入。

### 6.2 一句话结论

> 产品已经「功能齐全」，接下来的命题是让它「**身份一致、数据可用、训练可迁移**」。
> 最高性价比的两件事：**① 把口径与规则校正到真实行情（不改一行训练逻辑，只修正认知与边界）；② 把 537 万根真实日线变成「能挑、能练、能回看」的训练资产。**

### 6.3 三阶段实施顺序

| 阶段 | 目标 | 对应需求 | 建议顺序理由 |
|---|---|---|---|
| **阶段一：身份校正与底座接通**（最高优先） | 让产品口径与实际一致、让改造可被度量 | RQ-49～53（真实规则 + 口径改写 + 文档更新）、RQ-61～64（埋点接通 + 看板 + 数据源告警 + 密码找回） | 口径失真是**合规与信任问题**，且改动面小、收益最快；埋点不通则本轮所有投入无法度量 |
| **阶段二：把真实历史变成训练资产** | 建立唯一可持续的差异化壁垒 | RQ-36～42（回放升级：筛选器/多标的/书签）、RQ-43～47（标的治理 + 今日训练卡） | 这是竞品拿不走的卡位；但需在阶段一完成后再投入，避免「回放很酷但没数据可看」 |
| **阶段三：留存引擎与生态** | 把训练沉淀为长期目标与荣誉 | RQ-48、54～60（休市训练、打卡、成长档案、超额收益默认视角）、RQ-65（移动端与无障碍） | 需在回放与标的治理跑通、留存有正反馈后再做，否则功能空转 |

**阶段一内部串行建议**：口径改写（RQ-51～53）→ 真实规则（RQ-49～50）→ 埋点接通（RQ-61～62）→ 数据源告警与密码找回（RQ-63～64，可与前者并行）。口径排最前，是因为它是**唯一带有合规风险、且零技术依赖**的一项。

### 6.4 北极星指标与配套指标

| 层级 | 指标 | 说明 |
|---|---|---|
| **北极星** | **7 日留存率** | 模拟交易的价值取决于持续练习，留存是最诚实的度量（**前置条件：RQ-61 埋点必须先接通，否则该指标不可观测**） |
| 辅助（阶段二） | 人均每周回放训练次数 | 衡量回放训练是否被真正使用 |
| 辅助（阶段二） | 筛选器开启回放占比 | 衡量训练是「有目标」还是「随便拖一段」 |
| 辅助（阶段三） | 非交易时段活跃会话占比 | 衡量「休市即训练」是否起效 |

### 6.5 硬约束（排期压缩时不可砍除）

1. **RQ-51～53 口径与文档校正**必须与任何面向用户的改动同批上线：口径与实际不符是合规问题，不可延后。
2. **RQ-61 埋点接通**是北极星指标的前置条件——不接通则本轮改造无法度量与复盘，等于闭眼开车。
3. **RQ-42 回放与真实账户隔离**是回放训练的生命线：一旦污染战绩，榜单公信力不可逆崩塌。
4. **RQ-63 数据源状态可见**必须与真实行情同在：静默停更比报错更伤信任。
5. **所有训练/复盘/AI 输出保持「不构成投资建议」的显著披露**，不得含标的推荐与收益承诺。
